# Quickstart: validar KD-19 parte 1

1. `npm ci && npm run dev`, abrir o jogo, Clássico 1P.
2. Conferir: piso quadriculado, balcões vazios sem texto, 7 estações com desenho próprio, passe com "PASSE" e 🛎️.
3. Encher uma panela: boca acesa e barra verde; pronta: barra dourada→vermelha e ⚠️ piscando.
4. 2P: anéis e rótulos P1 (vinho) / P2 (azul); alvo tracejado na cor do jogador.
5. Equipar Mármore e Provence: paleta muda.
6. Gates: `npm run format:check && npm run lint && npm test && npm run build && npm run check-size`.

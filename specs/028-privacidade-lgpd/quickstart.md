# Quickstart: Privacidade (LGPD)

1. `npm test` — dicionário tem as 7 seções e os 2 marcadores; i18n sem chave faltante.
2. `npm run dev`:
   - Início → rodapé "Privacidade" → política.
   - Política → "excluir a conta" → `/perfil#excluir-conta` (visitante vê "entre para excluir"; logado cai na seção de exclusão).
   - Perfil logado → link "política de privacidade" na seção de exclusão.

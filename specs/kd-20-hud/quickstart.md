# Quickstart: KD-20

1. `npm ci && npm test` — `hudModel.test.js`, `match.test.js`, `kitchenUpdate.test.js` verdes.
2. `npm run dev`, abrir a página de jogo:
   - Clássico 1P: relógio desce de 3:00; barras mudam de cor; aos 0:00 o resumo aparece.
   - Livre 2P: relógio sobe; a tecla de pausa abre o menu; "Encerrar" fecha o turno.
   - Desafio: comandas #1…#12, 3 visíveis; fim ao entregar a 12ª.
   - Pausar/retomar: o relógio para e retoma do mesmo valor.
